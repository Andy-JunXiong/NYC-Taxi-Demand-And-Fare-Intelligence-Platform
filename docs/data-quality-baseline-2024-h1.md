# Data quality baseline: Yellow Taxi, 2024 H1

This baseline was generated by the governed Bronze-to-Silver build for the six
official monthly Yellow Taxi files from January through June 2024. Silver retains
all source rows; eligibility counts apply only to named Gold products.

## Quality observations

| Quality flag | Flagged rows |

| Negative fare | 315,747 |
| Negative total | 257,431 |
| Average speed above 100 mph | 6,266 |
| Candidate duplicate rows | 2 |

The official Taxi Zone lookup covers every reported pickup and dropoff ID in this
period. Candidate duplicates are deliberately not deleted because the source has no
guaranteed trip identifier.

Negative monetary values and invalid dropoff/duration values do not invalidate a
pickup event. They are excluded from the fare product but retained for demand,
which is why demand and fare eligibility differ by 322,846 rows.

## Gold result

The governed demand product contains 509,668 observed zone-hour groups representing
20,331,944 eligible pickups. Its lineage document records all six Silver checksums,
the Gold checksum, build timestamp, Git commit, and working-tree state.

## Interpretation

These values establish an observational baseline, not permanent release thresholds.
Future monthly builds should surface changes relative to this baseline. Blocking
thresholds should be introduced only after expected seasonality and upstream schema
behavior are understood.
