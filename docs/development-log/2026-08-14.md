## Forecast publication safety

The canonical forecast layout is now:

```text
data/processed/forecasts/
  releases/<release-id>/
    forecast.parquet
    lineage.json
    gate.json
  latest.json
```

Publication writes and verifies a complete immutable bundle before changing
canonical state with one atomic `latest.json` replacement. The resolver confines
all paths to the declared bundle and verifies artifact digests, release identity,
lineage metadata, and the passing gate. Monitoring and operational monitoring
use this resolver by default; explicit forecast paths remain available for
staging closure only.

Injected lineage-write, latest-write, and latest-replace failures all preserved
the previous canonical pointer. Failures after bundle finalization left only a
complete, noncanonical orphan release and no `.part` or pending-directory
residue. Detailed evidence is in
[`../publication-failure-safety-audit-2026-08-14.md`](../publication-failure-safety-audit-2026-08-14.md).
