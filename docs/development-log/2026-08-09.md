## Daily recursive evidence implementation and candidate v2

A later development slice implemented an out-of-time daily 24-hour recursive
shadow path in model validation. Each forecast day uses only observations before
that day, feeds predictions back only within the 24-hour horizon, reports daily
and segmented evidence, and is explicitly unable to promote or publish an
artifact. Matched tests cover temporal isolation, recursive feedback, reporting,
minimum-history enforcement, and the no-promotion boundary.

The governed 2022-01 through 2026-05 dataset was rebuilt locally from 53 public
TLC monthly partitions. All demand quality gates passed. The unified Gold row
count and SHA reproduced the earlier run exactly: 4,846,569 rows and
`463c141b9bdaad657d580990a108d1142b8ac44fb396bc4f68a6c15cbdaab4b9`.
The April cutoff also reproduced 4,726,034 rows.

The original feature semantics identified Memorial Day only through the binary
US-holiday feature, so the Sunday/Monday period used the global model outside
airports. Candidate v2 adds Memorial Day to the deterministic event calendar,
marks its Sunday eve and Monday as one event window, and makes training,
recursive inference, and forecast validation use the same `is_event_window`
routing boundary. Airport routing retains priority.
